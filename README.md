# CheckIn

## Веб-система цифрового учёта посещаемости студентов с использованием QR-кодов и аналитики

CheckIn — веб-система для автоматизации учёта посещаемости студентов в образовательной организации.

Система позволяет фиксировать присутствие студентов с помощью QR-кодов, вручную отмечать посещаемость при технических проблемах, обрабатывать причины отсутствия и предоставленные документы, а также получать аналитику и уведомления о проблемах с посещаемостью.
